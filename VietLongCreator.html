⚡ CHẠY TỰ ĐỘNG 24/7 — GITHUB ACTIONS (MIỄN PHÍ)
GitHub Pages không có server, nhưng GitHub Actions chạy được cron job miễn phí ngay trên repo của bạn — không cần VPS, không tốn tiền.
1
Tạo file workflow trong repo
Tạo .github/workflows/auto-upload.yml trong repo GitHub của bạn
2
Thêm Secrets vào repo
Settings → Secrets → YT_API_KEY, YT_OAUTH_TOKEN, YT_CHANNEL_ID
3
Xuất workflow file bên dưới
Nhấn nút → tải file → commit vào repo → GitHub tự chạy theo lịch
name: VietLong Auto Upload
on:
  schedule:
    - cron: '0 1,13 * * 1-5'  # 08:00 và 20:00 GMT+7 (T2-T6)
  workflow_dispatch:            # Chạy thủ công được

jobs:
  auto-upload:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with: { node-version: '18' }
      - run: npm install axios form-data
      - run: node .github/scripts/auto-upload.js
        env:
          YT_API_KEY: ${{ secrets.YT_API_KEY }}
          YT_OAUTH_TOKEN: ${{ secrets.YT_OAUTH_TOKEN }}
          YT_CHANNEL_ID: ${{ secrets.YT_CHANNEL_ID }}
          SONGS_PER_RUN: "2"
          KEYWORDS: "nhạc hot việt nam,remix 2025"

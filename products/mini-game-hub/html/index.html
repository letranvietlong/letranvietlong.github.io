Giới thiệu

App mở từ icon Màn hình chính có bộ nhớ riêng, không dùng chung với Safari — tiến trình chơi ở bên này không tự hiện ở bên kia. Dùng Lưu file rồi Khôi phục từ file để chuyển.

Muốn đổi sang icon mới: Lưu file → xoá icon → thêm lại vào Màn hình chính → Khôi phục từ file.
